# Matrix Neighbor Finder - C#

Projeto desenvolvido em C# para praticar matrizes bidimensionais.

## Funcionalidades

- Leitura de uma matriz M x N
- Busca por um valor informado
- Exibe:
  - posição
  - elemento à esquerda
  - elemento acima
  - elemento à direita
  - elemento abaixo
